При написании GraphQL-запросов/мутаций к Admin API — использовать существующий скилл
`shopify-admin` (для проектирования и объяснения операций) и `use-shopify-cli`
(для реального выполнения через CLI: auth, поиск по handle/SKU/location, изменение инвентаря).

Для верстки тем/секций — использовать скилл `shopify-liquid`.

## Файлы проекта (/mnt/project/)

Краткая карта всех файлов в базе знаний проекта — для быстрой ориентации, что где искать.

### Основные / служебные
- **CLAUDE.md** — этот файл, контекст проекта для Claude Code.
- **AGENDT.md** — пока пустой (зарезервирован, содержимого нет).
- **kotkoa_pod_pricing_calculator.xlsx** — калькулятор ценообразования POD-товаров для Kotkoa shop (себестоимость Printify + доставка + комиссия + маржа).

### Сводный конспект инсайтов
- **insites.md** — главный агрегированный файл инсайтов из нескольких транскрипций (LexAI про Printify, Learn with Shopify про Claude↔Shopify, Printify→Shopify интеграция, настройка политик Shopify, разбор прибыли реального магазина Кристины). У каждого раздела есть блок "Applicable to Kotkoa shop". Это основной файл для сверки, чтобы не дублировать инсайты из транскриптов ниже.

### Сырые транскрипты видео (источники для insites.md)
- **Connect_Pinterest_to_Shopify.md** — как подключить Pinterest (через приложение Pintahost) к Shopify; плюс отдельное видео про SEO-логику Pinterest (ключевые слова, доски/пины, автоматизация через Pin Generator).
- **Connect_Printify_to_Shopify.md** — пошаговая инструкция подключения Printify к Shopify: создание аккаунта, публикация товаров, настройка платежей (Shopify принимает деньги от клиента / Printify списывает за производство), важность нишевости.
- **Shopify_Policy_Configuration.md** — настройка юридических страниц (Return/Refund, Privacy, ToS, Shipping, Contact Info), навигация footer/header, платежи (Shopify Payments + 2FA), удаление дефолтных shipping zones, покупка домена, снятие пароля с магазина.
- **Print_on_Demand_Business_Models.md** — стратегический разбор: trend store vs brand store, выбор продукта/ниши/дизайна, ценообразование, три канала продвижения (маркетплейс/соцсети/email), сравнение Printify vs Printful vs Gelato (начало).
- **Promoting_Print_on_Demand_Designs.md** — 5 личных лайфхаков продвижения через сарафанное радио: носить свои товары, дарить их, брать кастомные заказы, не стесняться называть себя дизайнером, использовать личные соцсети.
- **Build_Shopify_Store_with_Claude.md** — как строить и вести Shopify-магазин через Claude Chat: создание store framework с нуля, подключение существующего магазина через коннектор, 3 готовых промпта (переписать описания товаров, ежедневный чек-ин, ценовая стратегия).
- **Print_on_Demand_Social_Media_Mistakes.md** — 5 типичных ошибок в соцсетях: спам товарами вместо контента (правило 80/20), плохой ad creative, неаккуратный текст на постах, реклама без прямой ссылки на покупку, непоследовательность публикаций.
- **Shopify_Store_Profit_Breakdown.md** — реальный кейс Кристины: помесячная динамика прибыли нового магазина с нуля (январь–май), методология Facebook Ads тестирования, рост конверсии, бандлинг.
- **Scaling_Shopify_Print_on_Demand_to_10K.md** — формула масштабирования до $10K/мес: математика продаж в день, "умный дизайн" (3 признака), широкий запуск дизайнов, catalog ads, постепенное наращивание бюджета.
- **Print_on_Demand_Instagram_Marketing.md** — маркетинг POD в Instagram: стратегия фото (заказ образцов, lifestyle-съёмка), Reels как основной формат, карусели, оптимизация профиля, хештеги.
- **TikTok_Shop_Print_on_Demand_Setup.md** — настройка TikTok Shop с нуля: бизнес-аккаунт, Seller Central, интеграция с Printify, продажи без подписчиков, Creator Program (инфлюенсеры за комиссию).

> Примечание: некоторые исходные транскрипты (например, Connect Printify to Shopify, Shopify Policy Configuration) частично уже свёрнуты в insites.md — при добавлении новых инсайтов сверяться с insites.md, чтобы не дублировать.
